🎓 College Website

📌 Features
🏫 Clean and simple college website design
📱 Responsive layout (works on mobile & desktop)
📄 Multiple pages (Home, About, Contact, etc.)
🎨 Styled using CSS
⚡ Lightweight and fast
🛠️ Tech Stack
HTML5 – Structure
CSS3 – Styling
JavaScript – Interactivity (if used)
